# Чип и Дейл спешат на помощь — 3D

Фанатский 3D-ремейк игры *Chip 'n Dale Rescue Rangers* (Capcom, NES, 1990) на Three.js.
Браузерная игра без сборки: статические файлы и ES-модули.

В главном меню два режима:

* **«Оригинальная игра: Пропавший котёнок»** — зоны оригинала в том же порядке, с геометрией, объектами и
  механиками, извлечёнными из ROM и сверенными с эмулятором.
* **«Новые приключения: Операция „Громовержец“»** — продолжение с собственным сюжетом и 11 новыми зонами
  по мотивам мультсериала.

## Запуск

Нужен локальный веб-сервер: из-за ES-модулей `index.html` нельзя открыть прямо с диска.

```
git clone https://github.com/dpronyaev/cnd3d.git
cd cnd3d
python serve.py
```

Затем откройте http://127.0.0.1:8123/.

`serve.py` — статический сервер с запретом кэширования, чтобы после обновления браузер всегда брал свежие файлы.
Обычный `python -m http.server 8123` тоже работает, но браузер может показывать старую версию модулей.
Three.js 0.160.0 загружается с CDN cdnjs, поэтому при первом запуске нужен интернет.

## Управление

| Действие | Игрок 1 | Игрок 2 |
|---|---|---|
| Движение | ← → | A D |
| Прыжок | Z или Пробел | G |
| Поднять / бросить / поставить | X или C | H |
| Присесть, спрятаться под ящиком | ↓ | S |
| Спрыгнуть с платформы | ↓ + прыжок | S + G |
| Бросок вверх | ↑ + бросок | W + H |
| Пауза, старт | Enter | |
| Статус | Shift | |
| Звук вкл/выкл | M | |
| Кадр NES 16:15 или широкий | V | |

Как в оригинале, ящик поднимают, упёршись в него сбоку. Брошенный ящик летит по прямой через весь экран.
Гайки не бросают, а ставят на клетку впереди, и из них можно строить башни.

**Геймпады.** Первый подключённый геймпад управляет игроком 1, второй — игроком 2. В игре на одного любой геймпад
управляет героем. Раскладка Xbox: крестовина или левый стик — движение, A — прыжок, X/Y — поднять или бросить,
Start — пауза, Back — статус, B — назад. Вибрация поддерживается. Браузер видит геймпад только после первого
нажатия кнопки. Экран «Геймпад» в главном меню показывает состояние кнопок.

**Steam Controller.** На рабочем столе Steam по умолчанию превращает его в клавиатуру и мышь, и браузер не видит
геймпада. Есть три способа:

1. Долго нажать кнопку «Вид» (⧉) слева. Steam включит набор «Геймпад», и появится виртуальный Xbox-контроллер.
2. В Steam: Настройки → Контроллер → «Раскладка для рабочего стола» → шаблон «Геймпад».
3. Ничего не настраивать: игра понимает клавиши профиля рабочего стола. Крестовина — движение, Y — прыжок,
   LB/R4/R5 — поднять или бросить, A — подтвердить, B — назад, «Меню» — пауза.

## Настройки

В пункте «Настройки» главного меню можно выбрать модели героев:

* **«Как в мультфильме»** (по умолчанию) — модели в стиле мультсериала 1989 года.
* **«Всратые модели»** — первые, упрощённые модели.

Выбор запоминается в браузере.

## Оригинальная игра

Уровни не нарисованы вручную. Их извлекает из ROM конвертер `tools/convert_levels.py`, а затем каждую зону
сверяю с эмулятором.

* **Геометрия** — блоки 16×16 из карт ROM, цвета по палитре NES (Mesen / Nestopia YUV). Камера показывает ровно
  15 рядов, как экран NES.
* **Механики по замерам в эмуляторе:**
  * прыжок 66–67 px с вершиной на 17-м кадре;
  * герой встаёт на уступ, если при падении ноги оказались внутри блока;
  * бросок ящика: 4 px за кадр по прямой, сквозь стены, до края экрана;
  * ящики — блоки карты, под некоторыми спрятаны цветы, звёзды и жёлуди;
  * гайки ставятся одна на другую.
* **Враги и боссы повторяют поведение оригинала.** Например, робот-бульдог ждёт, потом бежит на героя и
  перепрыгивает ящики. Электрические искры на проводах ранят, но их нельзя убить.

| Зона | Состояние |
|---|---|
| 0 — Улица и лаборатория | сверена с оригиналом: карта, объекты, двери, красный ящик, босс |
| A–J | извлечены из ROM, сверка с оригиналом ещё не проведена |

## Новые приключения

11 новых зон по мотивам мультсериала:

* штаб Спасателей;
* замок профессора Нимнула;
* пристань с Пи-ратами;
* прачечная Сиамских близнецов;
* притон Рэта Капоне;
* музей;
* ночной зоопарк;
* болото ведьмы Уинифред;
* подземный театр;
* дирижабль Нимнула;
* небоскрёб.

Между зонами идут кат-сцены. Играть можно всеми пятью Спасателями:

* Чип и Дейл;
* Гайка, которая планирует;
* Рокки, который ломает стены;
* Вжик, который летает.

## Музыка и звуки

15 мелодий и 25 эффектов получены из звукового движка оригинального ROM. Регистры APU записаны через эмулятор,
по ним восстановлены ноты и точки зацикливания. Затем всё перезвучено собственным синтезатором на Web Audio.
Ноты сохранены, звучание новое. Все треки есть в «Звуковом тесте».

```
src/engine/audio.js           музыкальный движок и звуковые эффекты

src/game/constants.js         физика, легенда тайлов, имена треков
src/game/level.js             разбор карт, геометрия, коллизии, двери
src/game/entities.js          герои, предметы, враги, боссы, платформы, снаряды
src/game/world.js             игровая сессия зоны: взаимодействия, камера, события
src/game/heroes.js            модели Спасателей в стиле мультсериала
src/game/models.js            враги, боссы, предметы и «всратые модели» героев
src/game/themes.js            текстуры, материалы, фоны
src/game/story.js             тексты кат-сцен, карты актов
src/game/levels_orig_data.js  зоны оригинала, сгенерированы tools/convert_levels.py
src/game/levelgen.js          генератор новых зон из «рецептов»

assets/music/*.json           треки: состояния каналов с частотой 60 Гц и точки зацикливания
tools/                        инструменты анализа ROM
```

## Инструменты анализа ROM

ROM в репозитории нет. Для инструментов нужен собственный дамп картриджа `ChipAndDale.nes` в корне проекта.
Для JS-инструментов один раз выполните `cd tools && npm install`, чтобы поставить эмулятор jsnes.

* `riplevels.py`, `convert_levels.py` — извлечение зон из ROM и сборка `src/game/levels_orig_data.js`.
* `validate_levels.mjs` — приближённая проверка, что выход и босс достижимы.
* `emu.js` — обёртка над jsnes: кадры, лог APU, доступ к RAM.
* `screenvisit.js` — запуск зоны с любого экрана через патч стартовой позиции и снимки объектов.
* `throwmeasure3.js`, `nutthrow.js`, `dogtrace.js`, `sparktouch.js`, `crateVsEnemy.js`, `cratecontents.js`,
  `bossfight0.js` — замеры механик и поведения врагов в оригинале.
* `sndscan.js`, `sndrec.js`, `apu2music.py` — извлечение музыки.
* `dis6502.py` — дизассемблер фиксированного банка.

## Права

Персонажи и вселенная принадлежат Disney, оригинальная игра — Capcom, музыка — Харуми Фудзита.
Это некоммерческий фанатский проект. Графика сделана процедурно, изображения и ROM оригинала в репозиторий не входят.
